# Часть III: Модель с тектоническим разломом

## Цель

Построить модифицированную 2D модель сейсмического разреза, в которой через центр исходной модели проходит тектонический разлом (сброс), рассекающий все 75 слоёв. Выполнить полноволновое моделирование на этой модели и сравнить результаты с исходной (бездефектной) моделью.

## Параметры разлома

| Параметр | Обозначение | Описание |
|----------|-------------|----------|
| Положение центра разлома | `fault_x` | X-координата точки пересечения разлома с поверхностью (по умолчанию — центр модели, ~5875 м) |
| Угол наклона | `fault_angle` | Угол наклона линии разлома относительно вертикали, градусы (0° — вертикальный разлом) |
| Смещение вдоль разлома | `fault_throw` | Вертикальное смещение слоёв вдоль плоскости разлома, метры (положительное — правый блок опущен) |

## Главы и задачи

### Глава I: Геометрия разлома (`dev_3_1_fault_geometry.py`)

**Исполнитель: ИИ**

**Задача:** Построить геометрию разлома — рассечь существующие границы 75 слоёв линией разлома и сместить правый блок вдоль плоскости разлома.

**Входные данные:**
- `data/dev_1_5_2_layer_boundaries_quadratic.npz` — границы слоёв
- Параметры разлома: `fault_x`, `fault_angle`, `fault_throw`

**Алгоритм:**
1. Загрузить границы слоёв из Главы 1.5
2. Вычислить линию разлома (прямая с заданным углом через заданную точку)
3. Для каждой границы слоя найти точку пересечения с линией разлома
4. Сместить правую часть каждой границы на `fault_throw` вдоль вертикали (с учётом угла)
5. Обработать зону разлома: обеспечить непрерывность геометрии у линии разлома (по необходимости — сгладить углы на ±1–2 элемента)
6. Визуализация: построить графики модели с разломом

**Выходные данные:**
- `data/dev_3_1_fault_layer_boundaries.npz` — модифицированные границы слоёв
- `img/dev_3_1_*.png` — графики геометрии с разломом

---

### Глава II: Материал модели с разломом (`dev_3_2_fault_material.py`)

**Исполнитель: ИИ**

**Задача:** Назначить упругие свойства материала для модели с разломом. Левый блок сохраняет исходный материал; правый блок смещается аналогично геометрии.

**Входные данные:**
- `data/dev_3_1_fault_layer_boundaries.npz` — геометрия с разломом
- `data/dev_1_6_layered_material.npz` — исходный материал
- Каротажные данные из `src/`

**Алгоритм:**
1. Для левого блока — исходная интерполяция материала (как в Главе I.6)
2. Для правого блока — та же интерполяция, но со смещением на `fault_throw`
3. В зоне разлома — интерполяция/экстраполяция для обеспечения непрерывности
4. Построение эйлеровой декартовой сетки материала (как в Главе I.7)

**Выходные данные:**
- `data/dev_3_2_fault_material.npz` — материал на декартовой сетке (5×5 м)
- `img/dev_3_2_*.png` — графики распределения Vp, Vs, ρ

---

### Глава III: Построение КЭ-сетки в Fidesys (`dev_3_3_fault_mesh.py`)

**Исполнитель: ИИ (генерация JOU-скриптов) + Пользователь (запуск в Fidesys)**

**Задача:** Сгенерировать JOU-скрипты для построения геометрии и сетки модели с разломом в CAE-Fidesys. Разлом разделяет модель на два блока с отдельными поверхностями.

**Действия ИИ:**
1. Сгенерировать JOU-скрипт создания вершин и сплайнов для левого блока
2. Сгенерировать JOU-скрипт создания вершин и сплайнов для правого блока
3. Сгенерировать JOU-скрипт создания поверхностей и назначения сетки
4. Учесть необходимость согласованной сетки на линии разлома (контакт)

**Действия пользователя:**
1. Запустить JOU-скрипты в Fidesys
2. Проверить качество сетки, при необходимости скорректировать параметры
3. Экспортировать FDS-модель

**Выходные данные:**
- `data/dev_3_3_model_vertex.jou` — создание вершин
- `data/dev_3_3_model_spline.jou` — создание сплайнов
- `data/dev_3_3_model_mesh.jou` — построение сетки
- `data/dev_3_3_model.fds` — FDS-модель (генерируется пользователем)

### Глава IV: FC-модель с материалом (`dev_3_4_fault_fc_model.py`)

**Исполнитель: ИИ**

**Задача:** Собрать FC-модель для Fidesys-SEMGPU: присвоить материалы элементам сетки, задать граничные условия, настроить демпфирование на краях.

**Входные данные:**
- `data/dev_3_3_model.fds` — сетка из Fidesys
- `data/dev_3_2_fault_material.npz` — материал с разломом

**Алгоритм:**
1. Загрузить FDS-модель (сетка)
2. Назначить материал каждому элементу на основе декартовой сетки
3. Задать демпфирующие слои на краях (PML/sponge)
4. Задать граничные условия (свободная поверхность сверху, поглощение снизу и по бокам)
5. Записать FC-модель

**Выходные данные:**
- `data/dev_3_4_model_calc.fc` — FC-модель для расчёта

### Глава VI: Полноволновой расчёт (`dev_3_6_fault_calculation.py`)

**Исполнитель: Пользователь (запуск расчёта) + ИИ (подготовка скрипта)**

**Задача:** Выполнить полноволновое моделирование на GPU-решателе Fidesys-SEMGPU для модели с разломом.

**Действия ИИ:**
1. Подготовить Python-скрипт расчёта (аналог `scripts/2_2_seismic_scripts/`)
2. Настроить параметры: 227 источников, 1176 приёмников, пульс Рикера f₀=30 Гц, время 4 с
3. Настроить запись результатов (сейсмограммы для каждого источника)

**Действия пользователя:**
1. Запустить расчёт на GPU-сервере
2. Контролировать ход расчёта
3. Собрать результаты

**Выходные данные:**
- `scripts/3_6_fault_seismic/` — скрипты расчёта
- `data/dev_3_6/` — результаты расчёта (сейсмограммы SEG-Y)

### Глава VIII: Сравнение и анализ (`dev_3_8_fault_comparison.py`)

**Исполнитель: ИИ**

**Задача:** Сравнить результаты моделирования для модели с разломом и без. Визуализировать влияние разлома на волновую картину.

**Анализ:**
1. Сравнение волновых полей (снимки в фиксированные моменты времени)
2. Сравнение сейсмограмм (gather) — выявление дифракций на разломе
3. Анализ отражений от смещённых границ
4. Идентификация характерных признаков разлома на сейсмограммах

**Выходные данные:**
- `img/dev_3_8_*.png` — сравнительные графики
- Выводы о сейсмическом отклике разлома

## Последовательность работ и зависимости

```
I Геометрия разлома (ИИ)
  │
  ├──► II Материал (ИИ)
  │       │
  │       ├──► V SEG-Y для Tesseral (ИИ)
  │       │
  │       └──► IV FC-модель (ИИ) ──► VI Расчёт (Пользователь + ИИ)
  │                                            │
  └──► III Сетка Fidesys (ИИ + Пользователь) ──┘     │
                                                         ▼
                                                   VII Merge (ИИ)
                                                         │
                                                         ▼
                                                   VIII Сравнение (ИИ)
```

## Критический путь

1. **I** → **III** → **IV** → **VI** → **VII** → **VIII**

Этапы II и V могут выполняться параллельно с III (они не зависят от сетки).

## Точки взаимодействия с пользователем

|------|----------------------|-----------|
| III | Запуск JOU-скриптов в Fidesys, экспорт FDS | IV |
| VI | Запуск расчёта на GPU-сервере | VII |
