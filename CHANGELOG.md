# CHANGELOG

## 0.0.71 [2025-09-05 12:00:00]

### Изменено
- `dev_1_6_material_update.py` — добавлено сглаживание верхних 10 точек каротажек (0–100 м) на 50% к среднему между скважинами
- `dev_3_1_fault_geometry.py` — параметризация файлов по углу разлома: суффикс `_a{angle}` (например `_a0`, `_a10`, `_a20`) во всех выходных файлах
- `dev_3_2_fault_material.py` — убрана логика сглаживания первого слоя; параметризация файлов по углу разлома (`fault_angle_param` + `angle_suffix`)
- `dev_3_3_fault_mesh.py` — кардинальная переработка генерации вершин: (1) слои горизонтальные и разорваны на линии разлома (левый блок — `orig_boundaries`, правый — `orig + throw`); (2) линия разлома строго прямая; (3) переменное число вершин per boundary (~50 м шаг), плотность сетки не сжимается при сужении секции; (4) мягкое слияние близких вершин на разломе с привязкой к прямой; (5) поверхности создаются через `create surface curve` по замкнутому контуру (вместо `skin curve`): добавлены вертикальные рёбра на 4 линиях раздела (4×75=300) и рёбра вдоль линии разлома (~128), `merge vertex all` перед созданием поверхностей
- `dev_3_4_fault_fc_model.py` — параметризация файлов по углу разлома (FC-модель, картинки)
- `dev_3_5_fault_segy.py` — параметризация файлов по углу разлома (SEG-Y файлы, картинки)
