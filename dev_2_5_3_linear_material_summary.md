# II.5.3. Линейная интерполяция материала FC по слоям

> Исторический этап главы II.5. Итоговые исправленные узловые SEG-Y и FC описаны в [главе II.5](dev_2_5_material_consistency_summary.md). Числа этого этапа относятся к прежнему `legacy`-комплекту; они не являются метриками окончательной пары.

> Дополнение II.5.4: причина различий исходных таблиц теперь установлена воспроизведением — сглаживание верхних отсчётов 0.75 и удаление нижних строк каротажа. Промежуточный FC совпадает с источником SEG-Y; расчётный FC воспроизводится из исторических данных. См. [проверку происхождения материала](dev_2_5_4_material_provenance_summary.md). Указанная ниже неопределённость происхождения относится к состоянию до этой проверки.

## Ответ

**Да: после исправления чтения TABLE и перехода к послойной линейной интерполяции материал существенно приблизится к SEG-Y по средней разности.** Однако основной выигрыш даёт восстановление пространственной зависимости вместо константы из первой строки. Линейная интерполяция сама по себе не устраняет различия сохранённых исходных таблиц FC и SEG-Y в слоях 1–5 и 75.

По сравнению с корректным ближайшим соседом линейная интерполяция не гарантирует меньшую разность с SEG-Y. Результат зависит от того, рассматривается растр как набор постоянных ячеек или как узловые значения с интерполяцией между ними.

## Метод

Прочитан тот же `data/dev_2_2_milen2Do5pore_full.fc` библиотекой `fc-model`. Для каждого из 75 материалов построена независимая триангуляция Делоне по **табличным координатам материала**, а не по всей совокупности узлов КЭ-сетки. Внутри треугольников линейно интерполируются **E, nu, rho**. Из результата вычисляются Vp, Vs и P-импеданс `Zp=rho*Vp`. Прямая интерполяция Vp/Vs или Zp дала бы несколько другой результат из-за нелинейности формул; здесь выбран вариант, соответствующий хранению упругих параметров в FC.

Каждая точка получает материал своего FC-элемента. Значения разных слоёв при интерполяции не смешиваются. Координаты перед триангуляцией сдвигаются к центру облака, без изменения масштаба осей: это устраняет численную проблему определения крайнего табличного узла у тонкого слоя на больших абсолютных координатах.

Использована та же квадратура 5×5 внутри 108859 QUAD8-элементов: **2721475 точек**, веса по площади. Общая область — **0–11750 м × 0–2650 м**. Карты показывают среднее подписанной разности по площади каждого элемента. Статистика рассчитана по отдельным точкам квадратуры. Во всех сравнениях этого исследования знаменатель — **SEG-Y**: `δ=100*(FC_method−SEG-Y)/SEG-Y`. Поэтому некоторые числа для ближайшего соседа отличаются от предыдущего отчёта, где в части сравнений знаменателем был FC.

Сравниваются три способа чтения FC: первая строка таблицы для всего слоя (воспроизведение найденного дефекта), ближайшая точка таблицы того же материала и линейная интерполяция по триангуляции слоя. Каждый способ сравнивается с двумя представлениями SEG-Y: физическими ячейками и билинейным чтением node_aligned. P-импеданс узлового растра вычисляется после интерполяции скоростей и плотности.

Это исследование восстановленного поля материала до волнового расчёта. Загрузка нового полного GLL-массива, его передача решателю и новая сейсмограмма здесь не вычислялись. Название «линейная интерполяция как в Fidesys» относится к предложенному пользователем принципу; точное равенство закрытому интерполятору Fidesys, включая его триангуляцию и правила на краях, не утверждается.

## Результаты относительно физических ячеек SEG-Y

Средние абсолютные относительные разности по площади, в порядке **ошибочная константа → ближайший сосед → линейная интерполяция**:

- **Vp:** 4.5855% → 1.0342% → **1.2703%**.
- **Vs:** 4.5887% → 1.0350% → **1.2712%**.
- **Плотность:** 1.0773% → 0.2277% → **0.2826%**.
- **P-импеданс:** 5.5840% → 1.2880% → **1.5789%**.

Таким образом, среднее расхождение уменьшается примерно в **3.5–3.8 раза** относительно ошибочного загрузчика. Линейная интерполяция при этом слегка проигрывает ближайшему соседу по MAE относительно постоянных ячеек, поскольку создаёт изменение свойств между табличными точками вместо ступенчатого поля.

Для линейного варианта P95 модуля разности составляет **7.0330% по Vp**, **7.0377% по Vs**, **1.4855% по плотности**, **8.5676% по Zp**. Это меньше соответствующих P95 ближайшего соседа: 7.6326%, 7.6386%, 1.6419%, 9.3309%. Следовательно, вывод «лучше/хуже» зависит также от выбранной меры: средняя ошибка несколько выше, но P95 ниже.

Большие локальные различия сохраняются: максимумы линейного варианта достигают **35.61% по Vp**, **35.63% по Vs**, **9.43% по плотности**, **48.40% по P-импедансу**, с SEG-Y в знаменателе. Улучшение средней не означает устранения проблемы разных исходных данных.

## Что остаётся после исключения разных версий материала

Отдельно выделены слои **6–74**, где исходные значения FC и SEG-Y совпадают до float32, точки внутри выпуклой оболочки таблицы и точки, принадлежащие одному слою по FC и растру.

В этой области ближайший сосед воспроизводит физические ячейки SEG-Y до округления. Для линейной интерполяции MAE составляет **0.3295% по Vp**, **0.3297% по Vs**, **0.0770% по плотности**, **0.4066% по Zp**. P95 — соответственно **1.3577%, 1.3587%, 0.3178%, 1.6759%**. Это собственно эффект различного представления одинаковых исходных точек. Он не равен нулю и локально может быть заметным при резком градиенте даже внутри слоя.

На картах сильные широкие зоны сохраняются вверху и в нижней части последнего слоя, где FC и SEG-Y уже содержат разные числа. Линейная интерполяция проходит через табличные значения своего FC и не может заменить их значениями из другого поколения растра.

## Если SEG-Y читать как узловое поле

При билинейном чтении node_aligned средние разности **ближайшего соседа → линейной интерполяции FC** равны:

- Vp: 1.5835% → **1.5458%**.
- Vs: 1.5846% → **1.5469%**.
- Плотность: 0.3568% → **0.3472%**.
- Zp: 1.9661% → **1.9190%**.

Здесь линейный вариант ближе и по MAE, и по P95, хотя выигрыш по средней небольшой. В чистой области слоёв 6–74 MAE линейного варианта по Vp равна 0.6302%, по Zp — 0.7777%. Остаётся разница между узловой трактовкой node_aligned и центрами исходных табличных ячеек, а также между билинейной интерполяцией Vp/Vs/rho и линейной интерполяцией E/nu/rho по треугольникам. Фактический режим чтения материала в Tesseral в задаче не установлен.

## Поведение на границах слоя

Табличные точки находятся в центрах ячеек. Их выпуклая оболочка не всегда покрывает весь FC-слой. Линейная интерполяция вне этой оболочки не определена, поэтому там явно применён ближайший сосед **своего материала**. Такие точки составили **1.8497% площади модели**. Для первого слоя отдельно доля составляет 60.799%: слой очень тонкий, и табличные центры не доходят до его поверхности и подошвы.

Для точек внутри оболочки MAE линейного варианта относительно физических ячеек: Vp 1.2032%, Vs 1.2040%, плотность 0.2697%, Zp 1.4998%. Таким образом, основной вывод сохраняется без зон с резервным чтением ближайшего соседа. Для точного воспроизведения Fidesys необходимо дополнительно согласовать его правила продолжения материала у границ, а также особенности выбора треугольников на регулярной сетке с неоднозначными диагоналями.

## Времена при x=6000 м

При линейном чтении FC, источнике на глубине 5 м и максимуме Рикера 30 Гц при 0.033333 с:

- Граница 73/74 на 2401.837 м: **2.09030 с**; по SEG-Y **2.09319 с**, разница **−2.894 мс**.
- Граница 74/75 на 2411.838 м: **2.09558 с**; по SEG-Y **2.09850 с**, разница **−2.922 мс**.
- Отметка 2495 м: **2.13577 с**; по SEG-Y **2.13870 с**.
- Дно 2650 м: **2.20325 с**; по SEG-Y **2.20993 с**, разница **−6.675 мс**.

Переход от ближайшего соседа к линейной интерполяции меняет время до нижних границ всего примерно на **0.44–0.55 мс**. Ошибка выбора первой строки меняла его примерно на **64 мс**. Поэтому главный шаг к согласованию кинематики — корректное чтение пространственной таблицы; выбор между NN и линейной интерполяцией в этой модели даёт существенно меньшую поправку.
