# Шаг 1: Анализ данных и заголовков SEG-Y

## 1. Структура новых NPZ-данных

Файл: `data/dev_2_3/research_seismic_sweep/x_{pos}/data.npz`  
Каждый файл — результат численного расчёта одного источника с центром в точке `x_center`.

| Ключ | Форма/тип | Описание |
|---|---|---|
| `x_center` | scalar float64 | Координата источника (м) |
| `dt` | scalar float64 | Шаг решателя ≈ 9.91×10⁻⁶ с |
| `t_end` | scalar float64 | Конечное время = 4.0 с |
| `sensor_x` | (1176,) float64 | Координаты сейсмоприёмников, 0..11750 м, шаг 10 м |
| `seismo_times` | (2000,) float64 | Моменты времени записи, 0..3.998 с, шаг ≈ 2002 мкс |
| `seismo_vx` | (2000, 1176) float64 | Компонента скорости Vx: (время × приёмники) |
| `seismo_vy` | (2000, 1176) float64 | Компонента скорости Vy: (время × приёмники) |
| `field_nodes_x/y` | (109771,) float64 | Координаты узлов сетки |
| `field_vx/vy/vmag` | (109771,) float64 | Снимок поля в момент `t_end` |

**Параметры записи:**
- Шаг сейсмограммы: dt_out ≈ 2002 мкс → для SEG-Y использовать **2000 мкс**
- Число отсчётов на трассу: **2000**
- Число приёмников на источник: **1176** (все точки поверхности, шаг 10 м)

**Источники в архиве:** x = 250, 300, 350, ..., 11500 м (шаг 50 м, всего 227 источников).  
Папки: `x_250/`, `x_300/`, ..., `x_11500/`.

## 2. Пример SEG-Y от заказчика (Tesseral)

Файл: `data/dev_2_3/example/21-01-26+GathAP-X.sgy`

**Бинарный заголовок:**
| Поле | Значение | Комментарий |
|---|---|---|
| Format | 1 | 4-байтовый IBM float |
| Samples | 1001 | Отсчётов на трассу |

**Структура файла:** 12635 трасс, 156 источников, до 80 приёмников на источник.

**Трассовые заголовки (ненулевые, ключевые):**

| Поле SEG-Y | Значение/диапазон | Пояснение |
|---|---|---|
| `TRACE_SEQUENCE_LINE` | 1..12635 | Глобальный номер трассы |
| `TRACE_SEQUENCE_FILE` | 1..12635 | То же |
| `FieldRecord` | 1..156 | Номер источника (gather) |
| `EnergySourcePoint` | 1..156 | То же |
| `CDP_TRACE` | 1..80 | Номер приёмника внутри gather |
| `TraceNumber` | 1..80 | То же |
| `TraceIdentificationCode` | 1 | Живая трасса |
| `DataUse` | 1 | Реальные данные |
| `CoordinateUnits` | 1 | Единицы координат: метры |
| `ElevationScalar` | -100 | Делить на 100 → глубина/отметка в метрах |
| `SourceGroupScalar` | -100 | Делить на 100 → X-координаты в метрах |
| `ReceiverGroupElevation` | -8 | −8 / 100 = −0.08 м ≈ поверхность |
| `SourceX` | (source_x × 100) | Координата источника × 100 |
| `GroupX` | (receiver_x × 100) | Координата приёмника × 100 |

| `CDP_X` | (midpoint_x × 100) | CDP midpoint × 100 |

| `CROSSLINE_3D` | = глобальный номер трассы | |

**Вывод по примеру:** координаты хранятся в единицах `1/100 метра` (умножены на 100), offset хранится в метрах напрямую.

| SampleInterval | 2000 мкс |

**Проблемы:**
- Трасс 18080, отсчётов 1501 — не совпадает с новыми данными (2000 отсчётов).
- Данные взяты из старого архива (`src/`), не из `research_seismic_sweep`.

- Источники начинались с x=250 м, но `SourceX` при первой трассе = 25000 / 100 = 250 м — координата правильная.
- `GroupX` первой трассы = 30000 / 100 = 300 м, offset=50 м — шаг 50 м ✓.
- Главная проблема: **данные из `research_seismic_sweep` не использовались**, числа отсчётов не совпадают.

## 4. Конфигурация сейсмограмм (план)

### Правый шаблон (Right spread)

- **Источники:** x_s = 250, 300, ..., 7450 м (шаг 50 м, **145 источников**)
- **Приёмники:** x_r = x_s + 50, x_s + 100, ..., x_s + 4000 м (**80 приёмников**)
- Индекс приёмника в массиве: `i_r = round(x_r / 10)`
- Итого трасс: 145 × 80 = **11600**
- Диапазон приёмников: 300..11450 м (в пределах модели ✓)

### Левый шаблон (Left spread)

- **Источники:** x_s = 4300, 4350, ..., 11500 м (шаг 50 м, **145 источников**)
- **Приёмники:** x_r = x_s − 50, x_s − 100, ..., x_s − 4000 м (**80 приёмников**)
- Индекс приёмника в массиве: `i_r = round(x_r / 10)`
- Итого трасс: 145 × 80 = **11600**
- Диапазон приёмников: 300..11450 м (в пределах модели ✓)

### Параметры SEG-Y для новых файлов

| Параметр | Значение |
|---|---|
| Format | 1 (4-byte IBM float) |
| Samples per trace | 2000 |
| Sample interval | 2000 мкс |
| ElevationScalar | -100 |
| SourceGroupScalar | -100 |
| CoordinateUnits | 1 (метры) |
| ReceiverGroupElevation | -8 (= 0 м поверхность) |
| TraceIdentificationCode | 1 |
| DataUse | 1 |
| SourceX | x_s × 100 |
| GroupX | x_r × 100 |
| offset | x_r − x_s (м, со знаком) |
| CDP_X | (x_s + x_r) / 2 × 100 |
| FieldRecord | номер источника (1-based) |
| CDP_TRACE | номер приёмника внутри gather (1-based) |
| TRACE_SEQUENCE_FILE | глобальный номер трассы |
