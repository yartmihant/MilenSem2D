# Описание исходных данных (`src/`)

Папка содержит первичные исходные данные для проекта двумерного сейсмического моделирования методом спектральных элементов (MilenSem2D).

---

## Каротажные данные скважин

| Файл | Описание |
|------|----------|
| `well1_Backus_Elast_Vp_Vs_rhob.txt` | Упругие параметры скважины 1 после осреднения по Бакусу: глубина (м), Vp (м/с), плотность (г/см³), Vs (м/с). Шаг 10 м, диапазон 12–2650 м. Используется в главах I и VI для интерполяции материала между скважинами. |
| `well_2_Backus_Elast_param_Vp_Vs_rhob.txt` | Аналогичный файл для скважины 2. Шаг 10 м, диапазон 12–2650 м. |
| `Координаты скважин.txt` | Координаты устьев двух скважин (X, Y) в метрах. Используется в главе II для построения профиля моделирования и привязки геометрии. |

## Глубинные поверхности (сейсмические горизонты)

**Директория:** `Depth_surfaces_for_Fidesys/`

11 файлов формата `hrz__<имя>_time_depth_itog.txt`, содержащих глубинные карты сейсмических горизонтов в формате: `[индекс_x, индекс_y, координата_x, координата_y, глубина_z]`. Около 374 000 точек каждый.

| Файл | Горизонт |
|------|----------|
| `hrz__0_surf_time_depth_itog.txt` | Дневная поверхность |
| `hrz__Upper_time_depth_itog.txt` | Верхний горизонт |
| `hrz__Under_0_time_depth_itog.txt` | Подповерхностный горизонт |
| `hrz__A_time_depth_itog.txt` | Горизонт A |
| `hrz__B_time_depth_itog.txt` | Горизонт B |
| `hrz__G_time_depth_itog.txt` | Горизонт G |
| `hrz__G1_time_depth_itog.txt` | Горизонт G1 |
| `hrz__G2_time_depth_itog.txt` | Горизонт G2 |
| `hrz__M_time_depth_itog.txt` | Горизонт M |
| `hrz__M1_time_depth_itog.txt` | Горизонт M1 |
| `hrz__U2_time_depth_itog.txt` | Горизонт U2 |

Используются в главе II для деформации конечно-элементной сетки в соответствии с геологической структурой.

## Координаты источников и геометрия расстановки

| Файл | Описание |
|------|----------|
| `Sources_coordinates` | Координаты пунктов возбуждения (источников) в глобальной системе координат (X, Y, Z). Шаг ~50 м вдоль профиля. |
| `Sources_coordinates_local.txt` | Те же координаты источников, пересчитанные в локальную систему координат модели (начало в центре профиля). |
| `polygon_around_profile.txt` | Координаты полигона (прямоугольника), ограничивающего область профиля. 5 точек (замкнутый контур) в глобальных координатах. |

| Файл | Описание |

## Тестовые данные Tesseral

**Директория:** `tesseral_example/`

Образцы SEG-Y файлов из программы конечно-разностного моделирования Tesseral. Используются в главе I (часть 2) как референсные данные для понимания формата SEG-Y.

| Файл | Описание |
|------|----------|
| `Vp_model.sgy` | Пример модели скорости продольных волн (60 501 трасса × 1 501 сэмпл, диапазон 1429–5140 м/с) |
| `Vs_model.sgy` | Пример модели скорости поперечных волн (785–2826 м/с) |
| `Density_model.sgy` | Пример модели плотности (1.86–2.55 г/см³) |
